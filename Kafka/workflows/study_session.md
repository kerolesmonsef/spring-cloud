# Workflow: Study Session

1. Find the first unticked box in `../TODO.md` and read that week in `learning_roadmap.md`. Ask the learner which topic of the week is next.
2. **Explain** (10–15 min): the concept with a diagram, then why Kafka designed it this way.
3. **Lab** (the main part): run commands or write Java code; look at real files/metrics.
4. **Quiz**: 3–5 questions, including one "what breaks if…" question.
5. **Notes**: add a short summary to `notes/week_NN.md` (what I learned, what confused me).
6. Tick the finished boxes in `../TODO.md` (the single tracker), log any numbers in its Results log, and summarize in chat.
